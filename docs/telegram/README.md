# Оформление бота в Telegram

Файлы в этой папке и тексты ниже — для настройки бота в [@BotFather](https://t.me/BotFather).

| Файл | Где использовать |
|---|---|
| `bot-avatar-640.png` | Аватар бота: `/setuserpic` → выбрать бота → отправить картинку как фото |
| `miniapp-banner-640x360.png` | Картинка мини-приложения: `/newapp` (или `/editapp`) → шаг «photo» |

## Тексты

**Имя бота** (`/setname`):

```
Samo Coffee
```

**Короткое описание** — показывается в профиле бота и при пересылке ссылки (`/setabouttext`, до 120 символов):

```
Свежая обжарка из Ташкента: каталог, заказ и подписка на кофе прямо в Telegram. Ответим на любой вопрос.
```

**Описание** — видно в пустом чате до нажатия «Старт» (`/setdescription`, до 512 символов):

```
☕ Samo Coffee — небольшая обжарочная в Ташкенте.

Что умеет бот:
• каталог зерна, дрип-пакетов и аксессуаров
• заказ и оплата прямо в Telegram
• подписка на кофе с доставкой по Ташкенту
• статус заказа и уведомления
• связь с бариста — ответим на любой вопрос

Нажмите «Старт», чтобы открыть меню.
```

## Мини-приложение (`/newapp`)

| Поле | Значение |
|---|---|
| Title | `Samo Coffee` |
| Description | `Магазин свежеобжаренного кофе: каталог, корзина и оплата в пару касаний.` |
| Photo | `miniapp-banner-640x360.png` |
| GIF | `/empty` |
| Web App URL | `https://<ваш-домен>/tma/` |
| Short name | `shop` → ссылка `https://t.me/<username_бота>/shop` |

Команды меню и кнопку «Открыть магазин» бот настраивает сам при запуске — их в @BotFather задавать не нужно.
